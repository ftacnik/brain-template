# Personal

Family, friends, health, finances. Same page templates as `entities/`, stricter rules:

- No account numbers, IBANs, balances, medical record identifiers, or anything you wouldn't want in a private GitHub repo. Summaries and decisions only.
- Raw financial data stays in its source systems. Finance pages here record *decisions and intentions* (budget targets, what to review), not transactions.
- WhatsApp captures from family chats go here, never into work entities.
- `/morning` reads `personal/personal goals.md` for personal priorities if it exists; `/ask` reads this folder only when the question is personal.

Suggested folders: `people/`, `health/`, `finances/`, `personal goals.md`. Create them when you have something to put there.
