# Timeline

One file per ISO week: `timeline/YYYY/YYYY-Wnn.md`. `/weekly` creates next week's file; `/ingest` appends to the current one.

File header and format:

```
# YYYY-Wnn · <first day>–<last day> <year>

<!-- One line per event/decision, newest at the bottom. Format:
- YYYY-MM-DD · [[entity]] · what happened / decided · next: … (src: …)
-->
```

Decisions are the most important thing in this repo. If in doubt, log it.
